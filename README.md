# Recall Killer™ – Memory Eraser Spray
> **"Spray it. Forget it."** · A Fictional Luxury Product Experience by **MAVERICKS**

Recall Killer™ (Model RK-404) is a premium, futuristic 3D e-commerce storefront for a fictional memory-management fragrance spray. Developed as a college project presentation by the **MAVERICKS** team.

![Hero Banner](public/images/campaign-banner.jpg)

---

## 🌟 Key Features

- **Cinematic 3D Interactive Hero:** Cursor-tracking 3D tilt perspective, floating bottle, and an interactive "Spray It / Undo" sandbox.
- **6 Memory Modes:**
  1. *Ex-It Mode* (Heartbreaks & broken promises)
  2. *Exam 404* (Exam trauma & academic stress)
  3. *Cringe Delete* (Embarrassing moments & awkward conversations)
  4. *Family Filter* (Unwanted relative interrogations)
  5. *Monday Reset* (Fresh start every week)
  6. *Sleep Mode* (Quiet 3 AM conversation replays)
- **3 Editions with Tiered Pricing:**
  - Basic Edition: ₹999
  - Professional Edition: ₹1,499 (Most Chosen)
  - Ultimate Edition: ₹2,999
- **Interactive Shopping Experience:**
  - Multi-angle product gallery (front, 360° views, studio showcase) with click-to-zoom.
  - Cart drawer with quantity controls, coupon codes (`FORGET10` for 10%, `MAVERICKS` for 15%), free shipping on ₹1,999+, and line item totals.
  - Wishlist and local order history persistence via `localStorage`.
  - Prototype checkout with validated form and instant fake order generation (`RK-xxxx`).
- **Comprehensive Brand Storytelling:**
  - *The Minds Behind the Madness:* 10 executive team member profiles (Amna, Aboodhi, Rinshin, Zida, Nahreera, Sinan, Savad, Sana, Niya, Naisha).
  - Competitor benchmark matrix (*Sleeping, Meditation, Writing Diaries vs. Recall Killer*).
  - 4-Phase future strategic roadmap.
  - FAQ accordion & official contact details.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Mohdrinshin/Recall-Killer-.git
cd Recall-Killer-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
